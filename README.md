# Lentera Pudar — The First Spark

**Lentera Pudar** adalah proyek full-3D stylized-realistic third-person action-adventure RPG dengan arah poetic dark fantasy.

## Current Technical Direction

- **Target runtime:** Unreal Engine 5.
- **Primary DCC:** Blender 5.2 LTS.
- **Unreal project:** `NOT INITIALIZED`.
- **Unreal gameplay systems:** `NOT_STARTED`.
- **Production assets:** `NOT_STARTED`.

Pemilihan atau dokumentasi teknologi tidak membuktikan runtime capability. Bedakan `DOCUMENTED`, `IMPLEMENTED`, `AVAILABLE`, `EXECUTED`, dan `VERIFIED`.
